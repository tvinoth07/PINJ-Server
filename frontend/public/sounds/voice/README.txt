PINJ - voice-over recordings for the brake indication
=====================================================
Put the 4 recordings in THIS folder with these names
(any of .mp3 / .wav / .m4a / .ogg):

  brake-overspeed   -> Brake_Applied = 1  Overspeed
  brake-nsb         -> Brake_Applied = 2  Normal Service Brake
  brake-fsb         -> Brake_Applied = 3  Full Service Brake
  brake-eb          -> Brake_Applied = 4  Emergency Brake

e.g. brake-nsb.mp3

Then: Settings -> SOUND -> VOICE-OVER -> RE-CHECK (or reload the page).
